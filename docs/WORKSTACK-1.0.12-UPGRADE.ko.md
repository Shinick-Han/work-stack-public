# Work Stack 1.0.12 업데이트 수정

1.0.8에서 Install and restart를 눌렀을 때 앱만 종료되거나, 별도 업데이트 실행 시 `active_profile_not_local`로 거부되는 두 문제를 수정합니다.

- 앱 디렉터리에서 시작된 설치도 PowerShell 현재 위치와 Windows 프로세스 현재 디렉터리를 외부로 옮긴 뒤 실행 파일을 교체합니다. 이미 설치된 1.0.8 실행기로 시작해도 적용됩니다.
- SSH 프로필이 선택된 경우 Windows 앱만 업데이트합니다. 등록된 SSH 프로필을 보존하고 원격 서버에 접속하거나 원격 저장소를 검사·백업·마이그레이션하지 않습니다.
- 기존 설치/설정이 있어야 하며, 선택 프로필이 바뀌면 중단합니다. 손상되거나 비활성화된 프로필을 임의로 허용하지 않습니다.
- 선택되지 않은 로컬 fallback 저장소를 SSH 데이터로 취급하지 않으며, 기존 포트와 데이터 경로도 유지합니다.

## 사용

Work Stack을 실행하고 업데이트 화면의 **Check now**를 누릅니다. **1.0.12** 다운로드 완료를 확인한 뒤 **Install and restart**를 누릅니다. 기존에 받은 1.0.11용 복구 명령은 다시 실행하지 않습니다.

재실행 후 Installed 1.0.12, 기존 SSH 프로필, Task 표시를 확인합니다. 이 릴리스는 Windows 클라이언트 업데이트이며 Linux 서버 설치본까지 자동 업데이트했다는 뜻은 아닙니다.

## 검증

- 설치기 authority 및 업데이트 관련 테스트 58개, Windows 설치 계약 테스트 32개 통과.
- 실제 공개 1.0.8 설치본에서 SSH 프로필 선택, 손상된 미사용 로컬 fallback, 사용 중인 로컬 포트를 구성한 상태로 1.0.12 설치 성공. 설정/등록/데이터/백업 파일 보존.
- 같은 조건에서 설정 처리 이후 실패를 주입했을 때 1.0.8 실행 파일 복구와 설정 보존 확인.
- 실제 1.0.8 업데이트 실행기를 앱 디렉터리에서 실행해 로컬 모드 설치·재시작 성공, HTTP owner ready 확인.
- 빌드 내부의 설치/연결 상태 smoke 검증 통과. 회사 SSH 서버 접속과 회사 PC 전체 동작은 사용자의 환경에서 확인해야 합니다.

로컬 빌드와 검증으로 게시한 릴리스입니다. GitHub Actions 전체 릴리스 workflow 실행, 코드 서명, 회사 환경 검증을 완료했다고 주장하지 않습니다. 1.0.11의 짧은 문서 기본 끝 행 처리 문제는 별도 후속 항목입니다.
