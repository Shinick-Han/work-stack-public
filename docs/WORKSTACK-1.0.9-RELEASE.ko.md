# Work Stack 1.0.9 설치 후보

이 문서는 개발 소스의 변경 사항을 설명한다. 설치 파일 제작·업그레이드 시험·공개 게시 결과는 별도 증거로 확인한다. 문서 작성 시점의 기존 설치본과 공개 릴리스는 1.0.8이다.

## 이번 변경

- Task의 Context에서 사용자가 선택한 로컬 Markdown 폴더의 문서를 미리 보고 참조를 연결할 수 있다. Obsidian vault도 이 방식으로 연결한다. 원문은 수정하지 않으며, 저장한 참조와 현재 원문의 변경 여부를 구분한다.
- 연결한 문서 중 사용자가 선택한 참조를 보조 컨텍스트 JSON으로 복사하거나 다운로드할 수 있다. 생성 전에 연결 상태와 원문을 다시 확인한다. 자동 전송이나 LLM 호출은 없다.
- Daily Review에서 보고서를 저장하고 목록·이력·확정·보관·복원을 관리한다. 저장된 보고서를 수정하면 새 버전이 추가되고, 확정본을 수정하면 초안으로 돌아간다. 이전 버전은 유지한다.
- Task·작업 공간·보고서를 전환할 때 늦게 도착한 응답이 다른 화면의 상태를 바꾸지 않도록 검증했다. 저장 결과가 불명확하면 원래 요청으로만 재시도하고 편집한 텍스트를 보존한다.

## 기존 설치본에서의 전환

새 설치 파일명은 `WorkStack-Setup-1.0.9.ps1`이다. 기존 설치본을 먼저 삭제하지 말고, 함께 제공되는 SHA-256 파일을 확인한 뒤 검증된 업그레이드 안내를 따른다. 별도 설치·검증이 끝나기 전에 개발 파일을 기존 실행 파일 위에 복사하지 않는다.

1.0.8과 동일한 collection schema 5를 사용한다. 연결한 문서의 참조 정보는 이 PC의 Work Stack 상태에 저장되며 원문은 선택한 외부 폴더에 남는다. 개인 vault를 지정하지 않았다면 프로그램이 임의로 찾아 연결하지 않는다.

## 검증 상태와 남은 범위

독립 검수와 합성 데이터 기반 실제 브라우저·HTTP 서버·Python 문서 저장소 결합 시험을 통과했다. 실제 제품 프런트엔드와 Windows WebView2 통신도 시험했지만 해당 시험의 폴더 선택기는 대체 구현이었다. 실제 폴더 선택창, 새 설치 파일의 첫 실행 및 업그레이드 결과는 추가로 확인한다.

이번 버전이 LLM Wiki 작성·양방향 Obsidian 동기화·Notion 인증·자동 보고 일정 등록을 제공한다는 뜻은 아니다. 원격 SSH 설치의 명령·검증 모듈은 후속 개발 중이며, 원격 설치 엔진은 아직 고정된 Linux 1.0.8 산출물만 허용한다. 현재 소스로 만든 Linux 1.0.9 산출물의 원격 설치는 지원 완료로 표시하지 않는다. 회사 환경 배포도 검증하지 않았다.
